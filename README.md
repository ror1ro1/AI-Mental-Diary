# AI Mental Diary

An interactive state-tracking application built with Python and Streamlit designed for personal productivity, logging emotional states, and tracking sleep metrics. The system maintains user inputs dynamically and aggregates data into localized weekly files.

## Features
- **Dynamic State Management**: Implements checklist behaviors for task verification and cross-day planning persistence.
- **Weekly File Aggregation**: Automatically calculates localized week ranges and appends structured entries into distinct weekly text databases.
- **Granular Metric Control**: Captures numeric parameters (energy scores, sleep durations) alongside unstructured contextual summaries.

## Tech Stack
- **UI Framework**: Streamlit
- **Language**: Python 3
- **File System**: Local I/O operations with automated datetime range processing
